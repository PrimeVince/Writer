# Writer — Creative Writing and Front-End Practice

A small personal website experiment combining original writing samples with an HTML and CSS presentation.

## Overview

The site presents three writing pieces:

- **The Slothful Quest for Evil** — a short fictional concept exploring sloth, morality and indifference.
- **The Increasing Rate of Human Deterioration** — an exploratory opinion-style piece about modern lifestyles and ageing.
- **Social Media as a Source of Income** — an overview of creator monetisation and the challenges of building an audience.

The project began as a way to practise structuring and styling a content-focused website. It is not a commercial writing-services portfolio.

## Technologies

- HTML5
- CSS3
- JavaScript (vanilla)

## Run locally

1. Clone or download the repository.
2. Open `index.html` in a modern browser.
3. Browse the writing samples and page sections.

## Project status

This is a learning and creative-writing experiment. The writing samples are included as personal practice, not presented as commissioned or professionally published work.
